Vice City Cover Studio turns photos and captions into multi-panel GTA-style cover art, exported as PNG. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — upload a photo (or use a sample), pick a layout, grade and post size, and export the cover as a PNG.
